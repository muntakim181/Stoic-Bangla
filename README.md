# Stoic-Bangla

**Stoic Philosophy made accessible for native Bangla speakers.**

## About The Project

Stoic philosophy is powerful, but the traditional English translations of these ancient quotes can sometimes be difficult to grasp—even for native English speakers. 

**Stoic-Bangla** bridges that gap. It pairs the original English Stoic quotes with easy-to-understand Bangla translations. Originally built as a personal tool to help me digest these philosophical concepts, I am now making it open-source for anyone who wants to explore Stoicism in their native language.

## Features

- **Bilingual Quotes:** Read the wisdom of Marcus Aurelius, Seneca, Epictetus, and others in both English and natural Bangla.
- **Ultra-Lightweight:** No heavy databases or complex backends. The entire dataset runs on a simple, lightning-fast JSON file.
- **AI-Assisted Translations:** The Bangla translation database was built entirely using the Gemini API to ensure the concepts were translated into accessible, everyday language.

## How It Was Built

This app was built using a **vibe coding** approach. The quotes were hand-picked and collected manually, while the heavy lifting of translating the philosophical nuances into Bangla was handled by the Gemini API. The architecture is kept intentionally simple and minimal, relying strictly on JSON.

## Disclaimer

Because the translation database was generated via AI, and philosophical quotes are deeply nuanced, there might be minor translation errors or areas where the context could be improved.
